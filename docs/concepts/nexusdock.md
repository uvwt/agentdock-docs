# What is NexusDock?

NexusDock is an optional self-hosted control center for people who use AgentDock on multiple devices.

It brings your Macs, Windows PCs, Linux hosts, and servers into one web console, lets them share Recall and Workflow data, and provides one MCP endpoint for AI clients.

If you only use one AgentDock device, you usually do not need NexusDock.

## What you can do

- connect to multiple AgentDock devices through one MCP endpoint;
- manage multiple AgentDock devices from one place;
- see which devices are online and check their current state;
- share Recall memory and Workflow data across devices;
- configure an AI client once instead of connecting to each AgentDock separately.

AgentDock still runs the actual work on each device. NexusDock brings those devices together; it does not replace them.
