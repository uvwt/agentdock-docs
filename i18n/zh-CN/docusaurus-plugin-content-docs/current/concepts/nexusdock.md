# 是什么

NexusDock 是面向多台 AgentDock 设备的可选自托管中心。

它可以把 Mac、Windows、Linux 主机和服务器上的 AgentDock 集中到一个 Web 控制台中，并共享 Recall 记忆和 Workflow 工作流数据，同时为 AI 客户端提供一个统一的 MCP 地址。

如果你只使用一台 AgentDock，通常不需要 NexusDock。

## 可以做什么

- 一个 MCP 连接多台 AgentDock；
- 在一个地方管理多台 AgentDock 设备；
- 查看哪些设备在线以及当前状态；
- 在多台设备之间共享 Recall 记忆和 Workflow 工作流数据；
- 只配置一次 AI 客户端，而不是分别连接每台 AgentDock。

实际的文件、命令、浏览器等操作仍由每台 AgentDock 执行。NexusDock 负责把这些设备集中起来，而不是替代 AgentDock。
